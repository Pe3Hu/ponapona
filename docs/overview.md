# Tantrix — обзор

## Режим

Единственный режим — **Chain** (Цепь). Соло.

Все 56 тайлов лежат на гексагональной сетке рубашкой вверх
компактной кучей. Игрок по одному открывает тайлы и выкладывает
их в единую цепь, соблюдая правила Tantrix.

## Ход игры (кратко)

1. Стартовая раскладка (см. `mode/chain.md`): в центре кучи
   один тайл убирается, три его соседа «через одного»
   открываются.
2. Игрок всегда видит 6 открытых тайлов кучи (пул).
3. Первый ход: два видимых тайла стыкуются — это ядро цепи.
   Добираются 2 новых открытых тайла.
4. Каждый следующий ход: один видимый тайл прикладывается к
   цепи по правилам Connect + Match и фиксируется навсегда.
   Добирается 1 новый открытый тайл.
5. Правила gobble и hole действуют всегда.
6. Три ограничения действуют, пока в куче есть скрытые тайлы.
7. Игра заканчивается победой (все 56 в цепи) или поражением
   (пул не пуст, но ни один видимый тайл нельзя приложить).

## Отображение

Вместо очков — показатели:

- **Chain size** — число тайлов в цепи.
- **Loop red / yellow / green / blue** — длина максимальной
  замкнутой линии каждого цвета.
- **Gobble count** — число незакрытых gobble.
- **Phase** — NORMAL / ENDGAME.
- **Result** — NONE / WIN / LOSE.

## Управление

| Действие                          | Кнопка                |
|-----------------------------------|-----------------------|
| Наведение на видимый тайл         | Предпросмотр (фантом) |
| Q / E                             | Вращение выделенного  |
| Поднять тайл (drag and drop)      | ПКМ по тайлу          |
| Снять поднятие                    | ПКМ по пустому/другому|
| Положить тайл                     | ЛКМ по слоту          |
| Вкл/выкл подсказок                | Пробел                |

Подсказка — фантомный дубликат выделенного тайла, повёрнутый
подходящим образом, в каждом допустимом слоте цепи. Пропадает,
когда тайл перестаёт быть выделенным.
