# Режим Цепь

## Игроки

Один.

## Компоненты

- `ChainData` — цепь.
- `PileData` — куча скрытых/открытых тайлов.
- `PoolData` — пул видимых тайлов (6 координат кучи).
- `SelectionData` — выделение.
- `HintData` — фантомы для подсказок.
- `GobbleData` — gobble и ограничения.
- `PhaseData` — фаза и результат.
- `DisplayData` — показатели для HUD.

## Старт

1. Все 56 тайлов кладутся в кучу рубашкой вверх на подрешётку
   (`Digest.pile_layout`).
2. Выбирается центральный тайл `C` (ближайший к центру формы
   кучи).
3. Три из шести соседей `C` по подрешётке (через одного —
   направления 0, 2, 4) переворачиваются лицом вверх.
4. Тайл `C` переносится на свободную клетку на границе кучи
   (клетка подрешётки без смежных граней с другими тайлами
   кучи).
5. Пул видимых = 6 тайлов.

## Пул

- `PoolData.coords` — всегда 6 координат открытых тайлов кучи.
- Первый ход: игрок забирает 2 тайла — 2 скрытых
  переворачиваются, пул снова 6.
- Каждый следующий ход: игрок забирает 1 тайл — 1 скрытый
  переворачивается.
- Если скрытых нет — пул уменьшается без добора.

## Ходы

### Первый ход

- Игрок выделяет видимый тайл `A`.
- Игрок выделяет видимый тайл `B`.
- Система ищет допустимый стык `A` и `B` (Match).
- Тайлы переезжают из кучи на поле цепи, становятся ядром.
- Куча пополняется двумя открытыми тайлами.

### Последующие ходы

- Фаза NORMAL: применяются три ограничения.
- Фаза ENDGAME: ограничения сняты, gobble и hole обязательны
  к заполнению.
- Определяются gobble и `forced_coords`.
- Если есть обязательный gobble — игрок обязан закрыть один
  из них. Прочие ходы запрещены.
- Иначе — свободный ход по базовым правилам (в NORMAL — плюс
  три ограничения).
- Тайл фиксируется навсегда.
- Добор одного скрытого, если есть.
- Если после добора `hidden_tiles.is_empty()` — смена фазы на
  ENDGAME.
- Пересчёт gobble, подсветки, подсказок, HUD.

### Подсветка gobble

- Обычный gobble — пульсация клетки.
- Обязательный — яркая рамка.
- Контролируемая сторона — затемнение клеток.
- Обновляется при изменении пула, выделения, Q/E.

## Конец игры

- **Победа** — `chain_size == Catalog.TILE_COUNT`.
- **Поражение** — пул не пуст, ни один видимый тайл нельзя
  приложить ни в один допустимый слот.

Проверка поражения — обход всех видимых тайлов и всех клеток
фронтира; если ни одна пара `(тайл, клетка, поворот)` не
проходит `is_place_valid` — поражение. Учитывать обязательство
закрывать gobble: если gobble закрывается — игра не закончена.

## Управление

### Предпросмотр (по наведению)

- Наведение ЛКМ на видимый тайл кучи = выделение.
- Если подсказки включены (Пробел) — показываются фантомы во
  всех допустимых слотах.
- Курсор ушёл — выделение снято, фантомы исчезают.

### Q / E

- Вращают выделенный тайл на −60° / +60°.
- Меняют, какие фантомы показываются.

### Подъём (ПКМ)

- ПКМ по видимому тайлу — тайл поднят (drag and drop).
- Фантомы видны, пока тайл поднят.
- Q / E вращают поднятый тайл.
- ПКМ по пустому/другому видимому тайлу — подъём снят.
- ЛКМ по фантом-слоту — тайл кладётся.

### Пробел

- Включает/отключает показ фантомов.
- Не влияет на выделение.

## Сцены

- `PileField` — куча (`Node2D`), дети `PileCell`.
- `ChainField` — цепь (`Node2D`), дети `ChainCell`.
- `PhantomLayer` — слой фантомов.
- `GobbleLayer` — подсветка gobble.
- `Hud` — показатели.

Сцена не хранит состояние. Вход — сеттер `data` (`ChainData`),
внутри — `connect_datas`, `connect_signals`, `init_*`.
