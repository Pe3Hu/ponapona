# Правила

## Базовые

1. **Connect.** Новый тайл ставится в пустую клетку поля цепи,
   смежную гранями с тайлом цепи. Первый ход — два видимых
   тайла кладутся рядом друг с другом, образуя ядро.

2. **Match.** Все соприкасающиеся рёбра двух тайлов должны
   совпадать по цвету.

## Фазы

`Bozo.Phase`:

| Фаза     | Когда                                 |
|----------|---------------------------------------|
| NORMAL   | В куче есть скрытые тайлы             |
| ENDGAME  | Все скрытые тайлы кучи перевёрнуты    |
| FINISHED | Победа или поражение                  |

Мешок в Chain — это скрытые тайлы кучи. Пока `hidden_tiles`
непуст, действуют три ограничения. Как только последний
скрытый тайл перевёрнут — фаза `ENDGAME`, ограничения сняты.
Правила gobble и hole продолжают действовать всегда.

## Gobble

Gobble — пустая клетка цепи с 3+ соседями-гранями, занятыми
тайлами.

| Соседей | Имя             |
|---------|-----------------|
| 3       | обычный gobble  |
| 4       | двойной gobble  |
| 5       | тройной gobble  |
| 6       | hole            |

Hole — частный случай gobble. Все правила gobble действуют на
hole без исключений.

### Обязанность заполнять

Если на поле цепи есть хотя бы один незаполненный gobble, и в
пуле есть тайл, который можно в него поставить при любом
повороте — игрок обязан поставить именно этот тайл именно в
этот gobble.

При нескольких gobble: если хотя бы один закрывается видимым
тайлом — любой другой ход запрещён. Игрок обязан закрыть один
из закрываемых.

Пока все закрываемые gobble не закрыты, ходы в произвольные
клетки фронтира запрещены.

### Подсветка gobble

- Все незакрытые gobble — базовый маркер.
- Закрываемые видимым тайлом — усиленный маркер.
- Если обязательный ход есть — необязательные слоты приглушены.

Обновляется при `tile_revealed`, `tile_taken`, `tile_placed`,
смене выделения, Q/E.

### Конфликты

- Несколько тайлов подходят в один gobble — игрок выбирает.
- Один тайл подходит в несколько gobble при разных поворотах —
  игрок выбирает gobble.
- Ни один видимый тайл не закрывает ни один gobble —
  ограничение снимается до следующего изменения пула.

## Hole

Hole — пустая клетка цепи со всеми шестью соседями-тайлами.
Ведёт себя как gobble: обязан быть закрыт при первой
возможности. Отдельного запрета на создание hole нет.

## Три ограничения (фаза NORMAL)

Пока в куче есть скрытые тайлы, дополнительно запрещено:

### 1. Одинаковые цвета вокруг нового gobble

Нельзя создать gobble, у которого все три обращённых к пустоте
ребра одного цвета. Если в клетке `C` после хода образуется
gobble с тремя рёбрами цвета `X` — ход недопустим. Неважно,
своим ли цветом или чужим.

### 2. Двойной gobble

Нельзя создать пустую клетку с 4+ соседями-тайлами. Это
запрещает двойные, тройные gobble и hole.

### 3. Контролируемая сторона

Если в клетке `A` есть незакрытый gobble, пустые клетки вдоль
той же стороны цепи `X`, `Y`, `Z` блокированы, пока `A` не
закрыт. Порядок заполнения — от `A` наружу. После закрытия `A`
можно играть в `X`; после `X` — в `Y`; после `Y` — в `Z`.

### Правило самозаполнения

Если заполнение gobble создаёт новый gobble с тремя одинаковыми
цветами или двойной gobble — исходный gobble нельзя заполнять
этим ходом. Выбирается другой тайл или другой поворот.

## Проверка хода

Ход (тайл `T` с поворотом `R` в клетку `C`) допустим, если:

- `C` пуста;
- `C` смежна гранями хотя бы с одним тайлом цепи;
- для каждого соседа `N` клетки `C` с тайлом: цвета обращённых
  рёбер совпадают;
- если есть обязательный gobble — `C` обязан быть одним из
  `forced_coords`;
- в фазе NORMAL:
  - ход не создаёт gobble с 3 одинаковыми цветами;
  - ход не создаёт клетку с 4+ соседями;
  - `C` не лежит на контролируемой стороне незакрытого gobble.

Первый ход в ядре: gobble и ограничения не применяются, только
Match.

## Снятие ограничений

При переходе в `ENDGAME` (все скрытые перевёрнуты) снимаются
только три ограничения. Проверки gobble, hole и обязанность
заполнять gobble сохраняются.

## Проверка подсказок

Для выделенного тайла `T` — множество пар `(C, R)`,
удовлетворяющих проверке хода. Если есть обязательный gobble —
подсказки только для `forced_coords`. Иначе — по всему
фронтиру.

## FAQ-инварианты

- Игрок всегда обязан заполнять gobble, даже в `ENDGAME`.
- После снятия ограничений двойные, тройные gobble и hole
  разрешены к созданию — но как только они возникли, их
  обязательно заполнять.
- Если заполнение gobble создаёт новый gobble — новый тоже
  обязан быть заполнен.
