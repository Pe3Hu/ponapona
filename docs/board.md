# Поле

## Сетка

Гексагональная сетка с аксиальными координатами
`Vector2i(q, r)`, pointy-top. Шесть направлений 0–5
(`Bozo.Direction`).

Смещения соседей — в `Digest.direction_to_offset`.
Противоположное направление — `(D + 3) % 6`.

Границы сетки — `Catalog.BOARD_RADIUS`.

## Две области

- **Куча** (`PileData`) — подрешётка с шагом 2. Здесь лежат
  скрытые и открытые тайлы до выкладывания в цепь.
- **Цепь** (`ChainData`) — вся гексагональная сетка. Сюда
  ставятся зафиксированные тайлы.

Поля независимы. Тайл из кучи «переезжает» в цепь, оставляя в
куче пустую клетку.

## Подрешётка кучи

Куча — треугольная подрешётка гексагональной сетки с шагом 2.
Генераторы: `(2, -1)` и `(1, 1)`. У каждой клетки кучи шесть
соседей по подрешётке на гекс-расстоянии 2, смежных граней нет.

Смещения соседей по подрешётке — в
`Digest.pile_neighbor_offsets`. Список стартовых позиций —
в `Digest.pile_layout` (56 координат максимально компактной
формы).

## Модели

### `PileData`

- `cell_to_cell: Dictionary[Vector2i, PileCellData]`
- `hidden_tiles: Array[TileData]`
- `get_cell(coord_)` — создать/получить клетку.
- `reveal_random()` — перевернуть один скрытый тайл.
- `move_to_chain(coord_)` — убрать тайл из кучи.
- `is_empty_hidden()` — все ли скрытые перевёрнуты.

`PileCellData`:
- `coord: Vector2i`
- `tile: TileData` (или `null`, если клетка пуста)
- `is_revealed: bool`

### `ChainData`

- `cell_to_cell: Dictionary[Vector2i, ChainCellData]`
- `get_cell(coord_)` — создать/получить клетку.
- `frontier` — пустые клетки, смежные гранями с тайлами цепи.
- `chain_size` — число тайлов в цепи.

`ChainCellData`:
- `coord: Vector2i`
- `tile: TileData` (или `null`)
- `rotation: int` (0–5)

## Сигналы

`PileData`:
- `tile_revealed(coord_)`
- `tile_taken(coord_)`

`ChainData`:
- `tile_placed(coord_)`
- `chain_cleared()`

Сцена не хранит состояние. Слушает сигналы и обновляет вид.

## Связность

Тайл ставится только в пустую клетку `ChainData`, смежную
гранями хотя бы с одним тайлом цепи. Первый ход — два тайла
кладутся рядом друг с другом, образуя ядро.
