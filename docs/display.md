# Отображение

## Показатели

| Поле          | Что                                        |
|---------------|--------------------------------------------|
| `chain_size`  | Число тайлов в цепи                        |
| `loop_red`    | Длина максимальной петли красного цвета    |
| `loop_yellow` | То же для жёлтого                          |
| `loop_green`  | То же для зелёного                         |
| `loop_blue`   | То же для синего                           |
| `gobble_count`| Число незакрытых gobble                    |
| `forced_hint` | bool: сейчас обязательный ход?             |
| `phase`       | NORMAL / ENDGAME                           |
| `result`      | NONE / WIN / LOSE                          |

`chain_size` пересчитывается при `tile_placed`.
`loop_*` пересчитываются при `tile_placed` (полный проход).
`gobble_count` и `forced_hint` — из `GobbleData`.

## Подсчёт петли цвета C

- Обойти все линии цвета `C` по рёбрам тайлов цепи.
- Для каждой линии проверить, замкнута ли она: ребро начала
  совпадает с ребром конца (та же клетка, тот же цвет ребра).
- Если замкнута — длина петли = число тайлов, через которые
  проходит линия.
- `loop_C` = максимум по всем замкнутым линиям цвета `C`.
- Если петель нет — 0.

## HUD

- `chain_size` — крупно.
- `loop_red`, `loop_yellow`, `loop_green`, `loop_blue` — по
  цвету, компактно.
- `gobble_count > 0` — счётчик gobble.
- `forced_hint == true` — текст «Заполните gobble».
- `phase == ENDGAME` — маркер «Ограничения сняты».
- `result != NONE` — экран результата.

## Результат

- `WIN` — экран победы.
- `LOSE` — экран поражения с показателем `chain_size`.
- `NONE` — обычная игра.

Числа — в `Catalog`. Соответствия — в `Digest`.
